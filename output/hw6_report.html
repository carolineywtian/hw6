Problem 4

1. Caching results

Reusing the handbook from the prompt cache cut the cost per document by 81.1%, from $0.00437 to $0.00083.

Every call sends the same instructions and 10,069-token handbook. I ran all 12 practice documents with caching on and with it off: 72 real model calls. The no-cache setup showed 0 cached tokens, which proves it really reused nothing.

How to read this

Each row is one document. The light dot is its cost without cache, the navy dot with cache, and the line is the saving.

Without cache, every document costs almost exactly the same, about $0.0044. That is because about 34,348 input tokens, almost all instructions and handbook, are paid for on every document, and the documents themselves add only a few hundred.

With cache, most documents drop to about $0.0005. Three (p01, p02, p08) had one call that missed the cache and paid to rewrite it.

Darker = more expensive per token. Without cache, 97% of the bill is cache writes: the provider still saves every prompt to the cache at $0.125 per 1M, more than plain input, even though nothing ever reuses it. With cache, most tokens are cheap cached reads.

The $0.00005 spread (1.2%) comes mostly from answer length. Output costs $0.50 per 1M tokens, so p05's 235-token answer costs more than p11's 144-token one.

Problem 6

3. What my defenses cost in tokens and dollars

The defenses save money: the fully defended agent costs $0.00031 per document, 41% less than the undefended one ($0.00053).

I switched each layer on by itself and ran all 12 practice documents (60 runs). Costs are from documents where no call missed the cache, because a random cache miss (about $0.0013 extra) would otherwise drown out the difference.

LayerWhat it doesModel calls per docExtra input tokens per docExtra $ per docChange
Code onlyCleans each document before the AI reads it; a web page shrinks to its visible text3-254−$0.000036-6.8%
Design onlyAI only copies 5 facts; code makes the decision, so 2 model calls per document instead of 32-11,899−$0.000220-41.6%
Prompt onlyAdds 311 tokens of security rules to every call (cached, so cheap)3+930+$0.000008+1.5%
All threeAll three layers together2-11,379−$0.000219-41.4%

Only the prompt layer adds tokens, and they sit in the cached part of the prompt. The design layer removes a whole model call per document, 11,899 input tokens, which is why the defended agent is the cheapest setup.
